### 1. 统计学的基本认识

统计学研究的不是孤立数字，而是通过数据认识现象、描述规律、支持判断。

| 概念 | 核心含义 | 例子 |
| --- | --- | --- |
| 统计工作 | 收集、整理、分析数据的活动 | 调查学生消费、整理企业销售额 |
| 统计资料 | 统计工作得到的数据材料 | 调查表、统计报表、数据表 |
| 统计学 | 研究数据方法的学科 | 如何抽样、如何制表、如何分析 |

统计学可以分成两类：

| 类型 | 解决的问题 | 简单理解 |
| --- | --- | --- |
| 描述统计 | 数据本身是什么样 | 整理数据、画图、算平均数 |
| 推断统计 | 总体可能是什么样 | 用样本推断总体 |

示例：调查 50 名学生的学习时长，画图和求平均数属于描述统计；用这 50 名学生推断全校学生的学习时长属于推断统计。

### 2. 总体、样本与统计量

| 概念 | 含义 | 例子：研究某班学生学习情况 |
| --- | --- | --- |
| 总体 | 研究对象的全体 | 全班所有学生 |
| 个体/总体单位 | 构成总体的每一个单位 | 每一名学生 |
| 样本 | 从总体中抽取的一部分个体 | 抽取的 10 名学生 |
| 参数 | 反映总体特征的指标，通常未知 | 全班平均成绩 |
| 统计量 | 根据样本计算出的指标 | 样本平均成绩 |

关系可以理解为：

```text
总体 → 抽样 → 样本 → 统计量 → 推断总体参数
```

关键点：

- 样本来自总体。
- 统计量来自样本。
- 推断统计的核心是用样本信息认识总体情况。

### 3. 标志、指标与变量

| 概念 | 说明 | 例子 |
| --- | --- | --- |
| 标志 | 说明总体单位特征的名称 | 性别、成绩、专业 |
| 标志值 | 标志的具体表现 | 男、85 分、统计学专业 |
| 指标 | 反映总体数量特征的名称或数值 | 平均成绩、及格率、总人数 |
| 变量 | 取值会变化的特征 | 年龄、收入、满意度 |

容易混淆的地方：

| 比较 | 标志 | 指标 |
| --- | --- | --- |
| 描述对象 | 个体特征 | 总体特征 |
| 常见阶段 | 调查阶段 | 整理和分析阶段 |
| 例子 | 每个学生的成绩 | 全班平均成绩 |

### 4. 统计数据的类型

按能否直接用数字表示：

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| 定性数据 | 反映类别或属性 | 性别、专业、满意度等级 |
| 定量数据 | 反映数量大小 | 成绩、收入、年龄 |

按变量类型：

| 类型 | 特点 | 例子 |
| --- | --- | --- |
| 分类变量 | 取值是类别，没有大小顺序 | 性别、专业 |
| 顺序变量 | 取值有等级顺序 | 满意度、产品等级 |
| 数值型变量 | 取值是数字 | 成绩、收入、年龄 |
| 离散变量 | 只能取有限或可数数值 | 人数、件数 |
| 连续变量 | 可在区间内连续取值 | 身高、体重、温度 |

按计量尺度：

| 尺度 | 能否分类 | 能否排序 | 差距有意义 | 倍数有意义 | 例子 |
| --- | --- | --- | --- | --- | --- |
| 定类尺度 | 是 | 否 | 否 | 否 | 性别、专业 |
| 定序尺度 | 是 | 是 | 否 | 否 | 满意度等级 |
| 定距尺度 | 是 | 是 | 是 | 否 | 摄氏温度 |
| 定比尺度 | 是 | 是 | 是 | 是 | 收入、年龄、销售额 |

按数据所处状态：

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| 截面数据 | 同一时点上多个对象的数据 | 某年各省 GDP |
| 时间序列数据 | 同一对象在不同时点的数据 | 某企业各月销售额 |

### 1. 数据来源

| 来源 | 含义 | 优点 | 局限 |
| --- | --- | --- | --- |
| 间接来源 | 已经存在的数据 | 成本低、获取快 | 不一定完全适合研究问题 |
| 直接来源 | 为当前研究专门收集的数据 | 针对性强 | 成本高、周期长 |

常见例子：

- 间接来源：统计年鉴、企业报表、数据库、政府公开数据。
- 直接来源：问卷调查、访谈、观察、实验。

### 2. 统计调查方案

一项调查开始前，要先把下面几件事想清楚：

| 项目 | 要回答的问题 |
| --- | --- |
| 调查目的 | 为什么调查 |
| 调查对象 | 调查范围是什么 |
| 调查单位 | 具体向谁调查 |
| 报告单位 | 谁负责上报资料 |
| 调查项目 | 要收集哪些变量 |
| 调查方法 | 用问卷、访问、观察还是实验 |

三个单位要分清：

| 概念 | 含义 | 例子：调查高校学生月消费 |
| --- | --- | --- |
| 调查对象 | 调查范围，也就是总体 | 全校学生 |
| 调查单位 | 具体被调查的单位 | 每一名学生 |
| 报告单位 | 提交资料的单位 | 各学院或班级 |

统计调查的基本要求：

| 要求 | 含义 |
| --- | --- |
| 准确 | 真实、客观地反映实际情况 |
| 完整 | 单位和项目不能遗漏 |
| 及时 | 在需要使用数据前完成收集 |

### 3. 数据收集方法

| 方法 | 具体形式 | 适用场景 |
| --- | --- | --- |
| 访问法 | 面访、电话调查、电脑辅助调查、座谈会、深访 | 调查态度、意愿、满意度 |
| 报告法 | 邮寄调查、单位报送、统计报表 | 组织或单位定期上报数据 |
| 直接观察法 | 观察法、实验法 | 记录行为、过程或实验结果 |

选择方法时要考虑：

- 想知道“怎么看”：适合问卷、访问、访谈。
- 想知道“怎么做”：适合观察法。
- 想知道“是否有影响”：适合实验法。

### 4. 抽样方法

概率抽样的特点是：总体中每个单位被抽中的概率可以事先确定，更适合用样本推断总体。

| 概率抽样方法 | 做法 | 适用情况 |
| --- | --- | --- |
| 简单随机抽样 | 每个单位被抽中的机会相同 | 总体单位差异不大 |
| 分层抽样 | 先分层，再在各层抽样 | 总体内部差异明显 |
| 整群抽样 | 先分群，再抽取若干群 | 总体分布范围广 |
| 系统抽样 | 按固定间隔抽取 | 名单排列较完整 |
| 多阶段抽样 | 分多个阶段逐步抽取 | 大范围复杂调查 |

非概率抽样的特点是：抽样方便，但样本代表性风险更大。

| 非概率抽样方法 | 做法 | 风险 |
| --- | --- | --- |
| 方便抽样 | 谁方便就调查谁 | 代表性较弱 |
| 判断抽样 | 研究者凭经验选择样本 | 主观性较强 |
| 自愿样本 | 被调查者自愿参与 | 容易偏向积极参与者 |
| 滚雪球样本 | 已有样本推荐新样本 | 样本圈层可能集中 |
| 配额抽样 | 按配额控制样本结构 | 不一定随机 |

一句话区分：

```text
概率抽样重在“可推断”，非概率抽样重在“方便获取”。
```

### 5. 统计误差

| 类型 | 含义 | 是否可避免 |
| --- | --- | --- |
| 登记性误差 | 填报、记录、录入过程中的错误 | 可以尽量避免 |
| 代表性误差 | 样本不能完全代表总体造成的误差 | 抽样调查中常见 |
| 系统性误差 | 调查设计或执行偏差导致的误差 | 应尽量避免 |
| 随机误差 | 抽样带来的随机波动 | 不能完全避免，但可以控制 |

注意：

- 数据不准确，后续整理和分析都会失去意义。
- 抽样调查不可能完全没有误差，关键是控制误差。

### 6. 统计分组

统计分组是根据研究目的，把总体单位按照某个标志分成若干组。

| 内容 | 说明 |
| --- | --- |
| 作用 1 | 划分总体类型 |
| 作用 2 | 反映内部结构和比例关系 |
| 作用 3 | 揭示现象之间的相互依存关系 |

分组原则：

| 原则 | 含义 |
| --- | --- |
| 科学性 | 分组要符合研究目的 |
| 完备性 | 每个单位都能归入某一组 |
| 互斥性 | 每个单位只能归入一个组 |

分组类型：

| 分类角度 | 类型 | 例子 |
| --- | --- | --- |
| 按标志性质 | 品质标志分组 | 按性别、专业分组 |
| 按标志性质 | 数量标志分组 | 按成绩、收入分组 |
| 按标志个数 | 简单分组 | 只按一个标志分组 |
| 按标志个数 | 复合分组 | 同时按多个标志分组 |

### 7. 分布数列、频数与频率

分布数列是把总体单位按某一标志分组后，列出各组单位数或各组所占比重的结果。

| 概念 | 含义 |
| --- | --- |
| 组别 | 分成的各个类别或区间 |
| 频数 | 各组单位数 |
| 频率 | 各组单位数占总体单位数的比重 |

组距式数列常见概念：

| 概念 | 含义 |
| --- | --- |
| 组限 | 每一组两端的数值 |
| 组距 | 区间长度 |
| 组中值 | 上限和下限的中点 |
| 开口组 | 只有上限或只有下限的组 |

常用公式：

```text
频率 = 频数 / 总数
组距 = 上限 - 下限
组中值 = (上限 + 下限) / 2
频数密度 = 频数 / 组距
```

等距分组与不等距分组：

| 类型 | 特点 | 比较方式 |
| --- | --- | --- |
| 等距分组 | 各组组距相同 | 可直接比较频数或频率 |
| 不等距分组 | 各组组距不同 | 应比较频数密度 |

### 8. 统计表

统计表是用表格形式表示整理后的统计数据，是统计数据最规范的表现形式之一。

| 构成 | 说明 |
| --- | --- |
| 总标题 | 说明表格整体内容 |
| 横栏标题 | 说明横向项目 |
| 纵列标题 | 说明纵向项目 |
| 横行与纵列 | 承载数据结构 |
| 注释与资料来源 | 补充说明数据口径 |

统计表设计要点：

| 要点 | 说明 |
| --- | --- |
| 标题清楚 | 标题要说明研究对象、范围和数据口径 |
| 单位清楚 | 计量单位要清楚 |
| 对齐规范 | 数字通常右对齐，小数点位置保持一致 |
| 空项处理 | 没有数字的单元格可用“--”表示 |
| 必要说明 | 必要时加注释或资料来源 |

列联表也叫交叉表，是两个或两个以上变量交叉分类形成的频数分布表。

| 性别 | 低消费 | 中消费 | 高消费 | 合计 |
| --- | ---: | ---: | ---: | ---: |
| 男 | 18 | 52 | 30 | 100 |
| 女 | 20 | 57 | 23 | 100 |
| 合计 | 38 | 109 | 53 | 200 |

列联表适合观察不同类别之间的分布差异。

### 9. 统计图选择

不同数据类型适合不同图形：

| 数据类型 | 推荐图形 | 主要作用 |
| --- | --- | --- |
| 分类数据 | 条形图、帕累托图、饼图、环形图 | 展示类别构成或类别差异 |
| 顺序数据 | 累计频数图、累计频率图 | 展示等级累积情况 |
| 分组数值数据 | 直方图 | 展示数值分布形态 |
| 未分组数值数据 | 茎叶图、箱线图 | 保留细节或比较分布 |
| 时间序列数据 | 线图 | 展示变化趋势 |
| 两个变量 | 散点图 | 展示相关关系 |
| 多变量 | 气泡图、雷达图 | 展示多维差异 |

常见图形区分：

| 图形 | 适合数据 | 注意点 |
| --- | --- | --- |
| 柱形图 | 分类数据 | 柱宽没有实际意义 |
| 直方图 | 分组数值数据 | 面积或高度反映频数/频率 |
| 茎叶图 | 小批量数值数据 | 既保留原始数据，又能看分布 |
| 线图 | 时间序列数据 | 适合观察趋势变化 |
| 饼图 | 一个总体的结构 | 类别太多时效果变差 |
| 环形图 | 多个总体结构比较 | 比饼图更适合并列比较 |
| 散点图 | 两个数值变量 | 可观察相关方向和强弱 |

图形选择小口诀：

```text
分类看条形，结构看饼环；
分布看直方，小样本看茎叶；
趋势看线图，关系看散点。
```

### 1. 数据特征的观察角度

看一组数据，通常从三个角度入手：

| 角度 | 回答的问题 | 常见指标 |
| --- | --- | --- |
| 集中趋势 | 数据中心在哪里 | 众数、中位数、平均数、分位数 |
| 离散趋势 | 数据差异有多大 | 极差、四分位差、方差、标准差、离散系数 |
| 分布形状 | 数据分布长什么样 | 偏态、峰态、箱线图 |

### 2. 集中趋势

| 指标 | 含义 | 适用提示 |
| --- | --- | --- |
| 众数 | 出现次数最多的变量值 | 分类数据常用 |
| 中位数 | 排序后位于中间位置的数 | 不易受极端值影响 |
| 平均数 | 全部数值总和除以个数 | 数值型数据常用 |
| 分位数 | 按位置把数据分成若干部分 | 常用于描述位置 |

### 3. 离散趋势

| 指标 | 含义 | 特点 |
| --- | --- | --- |
| 极差 | 最大值 - 最小值 | 简单，但受极端值影响大 |
| 四分位差 | 上四分位数 - 下四分位数 | 较少受极端值影响 |
| 平均差 | 各数值与平均数离差绝对值的平均 | 反映平均偏离程度 |
| 方差 | 离差平方的平均 | 常用于理论分析 |
| 标准差 | 方差的平方根 | 单位与原数据一致 |
| 离散系数 | 标准差 / 平均数 | 适合比较不同水平或不同单位的数据 |

例子：

| 对象 | 平均体重 | 标准差 | 离散系数 |
| --- | ---: | ---: | ---: |
| 牛 | 80 kg | 18 kg | 22.5% |
| 羊 | 15 kg | 3 kg | 20% |

结论：比较离散程度时，不能只看标准差。平均水平不同的对象，应看离散系数。

### 4. 分布形状

| 形状 | 含义 | 图形特征 |
| --- | --- | --- |
| 对称分布 | 左右大致均衡 | 中心两侧形态接近 |
| 右偏分布 | 尾巴在右边 | 少数较大值拉长右尾 |
| 左偏分布 | 尾巴在左边 | 少数较小值拉长左尾 |
| 峰态 | 分布尖峭或平坦程度 | 峰越高，数据越集中在中心附近 |

### 5. 箱线图

箱线图可以同时展示位置、离散程度和异常值。

```text
最小值 ─ Q1 ─ 中位数 ─ Q3 ─ 最大值
```

| 元素 | 含义 |
| --- | --- |
| Q1 | 下四分位数 |
| 中位数 | 数据中间位置 |
| Q3 | 上四分位数 |
| 箱体长度 | 中间 50% 数据的离散程度 |
| 异常值 | 明显偏离主体的数据点 |

读箱线图时看三点：

- 箱体越长，中间数据越分散。
- 中位数偏向一侧，分布可能不对称。
- 异常值多，说明数据中存在特殊点。

## 快速判断题

| 问题 | 参考答案 |
| --- | --- |
| “满意度：很不满意、不满意、一般、满意、很满意”属于什么变量？ | 顺序变量 |
| 展示班级性别构成，适合什么图？ | 条形图、饼图或环形图 |
| 展示学生成绩分布，适合什么图？ | 直方图、茎叶图或箱线图 |
| 展示企业各月销售额变化，适合什么图？ | 线图 |
| 两个班平均分一样，成绩分布一定一样吗？ | 不一定，还要看离散程度和分布形状 |
| 分组组距不同，能直接比较频数吗？ | 不能，应比较频数密度 |

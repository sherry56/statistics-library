统计学重难点与易混淆点梳理

# 统计学重难点与易混淆点梳理

## 一、总体、个体、样本的区别

### 1. 基本概念

| 概念 | 含义 | 关键词 |
| --- | --- | --- |
| 总体 | 在一定研究目的下，所有研究对象的全体 | 全部、研究范围 |
| 个体/总体单位 | 构成总体的每一个单位 | 每一个、单个对象 |
| 样本 | 从总体中抽取出来的一部分个体组成的集合 | 部分、抽取、集合 |

### 2. 例子说明

例 1：研究某班学生的数学成绩。

| 概念 | 对应内容 |
| --- | --- |
| 总体 | 该班所有学生 |
| 个体 | 该班每一名学生 |
| 样本 | 从该班抽取的 10 名学生 |

例 2：研究某市居民月收入水平。

| 概念 | 对应内容 |
| --- | --- |
| 总体 | 该市所有居民 |
| 个体 | 该市每一位居民 |
| 样本 | 抽取的 1000 位居民 |

例 3：研究某企业生产设备的使用情况。

| 概念 | 对应内容 |
| --- | --- |
| 总体 | 该企业所有生产设备 |
| 个体 | 每一台生产设备 |
| 样本 | 抽查的若干台生产设备 |

### 3. 易混淆点

- 总体不是“很多数据”，而是研究对象的全体。
- 个体不是“某个数据值”，而是构成总体的单个对象。
- 样本不是“一个个体”，而是一部分个体组成的集合。
- 同一个对象在不同研究目的下，可能对应不同总体。

例：研究“某班学生学习情况”，总体是学生；研究“某班学生各科成绩”，总体也可以理解为该班学生的各科成绩记录，取决于研究对象如何界定。

### 例题

例题 1：为了研究某校本科生的月生活费水平，随机抽取 300 名本科生进行调查。请指出总体、个体和样本。

答案：

- 总体：某校全体本科生。
- 个体：某校每一名本科生。
- 样本：被抽取的 300 名本科生。

例题 2：为了研究某工厂生产的灯泡寿命，从当天生产的 5000 个灯泡中随机抽取 100 个进行检测。请指出总体、个体和样本。

答案：

- 总体：当天生产的 5000 个灯泡。
- 个体：每一个灯泡。
- 样本：抽取检测的 100 个灯泡。

例题 3：某市要研究居民家庭汽车拥有情况，抽取 2000 户家庭进行调查。这里的个体是“人”还是“家庭”？

答案：个体是家庭。因为研究对象是居民家庭汽车拥有情况，调查单位是每一户家庭，而不是每一个人。

## 二、数据的四个计量尺度对比

### 1. 四个尺度总表

| 尺度 | 能否分类 | 能否排序 | 差距是否有意义 | 倍数是否有意义 | 常见例子 |
| --- | --- | --- | --- | --- | --- |
| 定类尺度 | 能 | 不能 | 无意义 | 无意义 | 性别、专业、血型、地区 |
| 定序尺度 | 能 | 能 | 不精确 | 无意义 | 满意度等级、产品等级、学历层次 |
| 定距尺度 | 能 | 能 | 有意义 | 无意义 | 摄氏温度、考试标准分 |
| 定比尺度 | 能 | 能 | 有意义 | 有意义 | 收入、年龄、身高、销售额 |

### 2. 判断方法

| 判断问题 | 如果答案是 | 对应尺度 |
| --- | --- | --- |
| 只能区分类别，不能比较大小？ | 是 | 定类尺度 |
| 可以排序，但等级间差距不精确？ | 是 | 定序尺度 |
| 差距有意义，但没有绝对零点？ | 是 | 定距尺度 |
| 有绝对零点，倍数比较有意义？ | 是 | 定比尺度 |

### 3. 典型易错点

1. 数字编码不等于数值型数据。

例如：性别用 1 表示男、2 表示女，这里的 1 和 2 只是编码，不能说“女是男的 2 倍”，所以仍然是定类尺度。

2. 满意度打分要看是否真正有等距含义。

如果满意度为“很不满意、不满意、一般、满意、很满意”，通常是定序尺度；如果设计成严格量表并默认相邻分值差距相同，分析时可能近似按定距数据处理。

3. 摄氏温度不是定比尺度。

20 摄氏度不是 10 摄氏度的 2 倍热，因为摄氏度的 0 点不是绝对零点；摄氏温度属于定距尺度。

4. 收入、年龄、身高通常是定比尺度。

这些变量有实际零点，差距和倍数都有意义。

### 例题

例题 1：判断下列变量分别属于哪种计量尺度：性别、满意度等级、摄氏温度、月收入。

答案：

| 变量 | 计量尺度 | 理由 |
| --- | --- | --- |
| 性别 | 定类尺度 | 只能分类，不能排序 |
| 满意度等级 | 定序尺度 | 可以排序，但等级差距不精确 |
| 摄氏温度 | 定距尺度 | 差距有意义，但倍数无意义 |
| 月收入 | 定比尺度 | 有绝对零点，倍数有意义 |

例题 2：学生学号为 2024001、2024002、2024003，是否属于定比尺度数据？

答案：不是。学号虽然用数字表示，但只是身份编码，不能做大小、差距和倍数比较，属于定类尺度。

例题 3：某商品满意度用 1、2、3、4、5 表示“很不满意”到“很满意”。这个变量通常属于什么尺度？

答案：通常属于定序尺度。虽然用数字表示，但 1 到 2 与 4 到 5 的差距不一定完全相同，主要体现等级顺序。

## 三、品质标志和数量标志

### 1. 基本区别

| 类型 | 含义 | 表现形式 | 例子 |
| --- | --- | --- | --- |
| 品质标志 | 说明总体单位属性或类别的标志 | 通常用文字表示 | 性别、民族、专业、产品等级 |
| 数量标志 | 说明总体单位数量特征的标志 | 通常用数值表示 | 年龄、收入、成绩、产量 |

### 2. 进一步理解

| 比较角度 | 品质标志 | 数量标志 |
| --- | --- | --- |
| 反映内容 | 性质、类别、属性 | 数量大小 |
| 是否可计算平均数 | 通常不能 | 通常可以 |
| 是否能排序 | 有些能，有些不能 | 通常能 |
| 常见分组 | 品质标志分组 | 数量标志分组 |

### 3. 例子

| 标志 | 判断 | 原因 |
| --- | --- | --- |
| 性别 | 品质标志 | 表示类别 |
| 专业 | 品质标志 | 表示类别 |
| 产品等级 | 品质标志 | 表示等级属性 |
| 年龄 | 数量标志 | 表示数量大小 |
| 月收入 | 数量标志 | 表示数量大小 |
| 考试成绩 | 数量标志 | 表示分数大小 |

### 4. 易混淆点

- 品质标志也可能有顺序，如产品等级、满意度等级，但它仍然反映属性或等级，不是严格数量标志。
- 数字编码后的品质标志仍然是品质标志。例如专业编号 01、02、03 只是代码。
- 数量标志可以继续分为离散型和连续型。

| 数量标志类型 | 特点 | 例子 |
| --- | --- | --- |
| 离散型数量标志 | 取值通常是整数，可数 | 人数、件数、企业数 |
| 连续型数量标志 | 可在区间内连续取值 | 身高、体重、收入、时间 |

### 例题

例题 1：判断下列标志是品质标志还是数量标志：性别、年龄、专业、考试成绩、产品等级。

答案：

| 标志 | 类型 |
| --- | --- |
| 性别 | 品质标志 |
| 年龄 | 数量标志 |
| 专业 | 品质标志 |
| 考试成绩 | 数量标志 |
| 产品等级 | 品质标志 |

例题 2：某企业员工的“岗位编号”用 01、02、03 表示，岗位编号属于品质标志还是数量标志？

答案：品质标志。编号只是代码，表示不同岗位类别，不能当作数量大小进行计算。

例题 3：“家庭人口数”和“家庭年收入”都属于数量标志吗？二者有什么区别？

答案：都属于数量标志。家庭人口数是离散型数量标志，通常取整数；家庭年收入是连续型数量标志，可在区间内连续变化。

## 四、统计调查的组织形式对比

### 1. 常见组织形式

| 组织形式 | 调查对象范围 | 主要特点 | 优点 | 局限 | 适用场景 |
| --- | --- | --- | --- | --- | --- |
| 普查 | 全部单位 | 一次性、全面调查 | 资料全面、系统 | 成本高、工作量大 | 人口普查、经济普查 |
| 抽样调查 | 部分单位 | 用样本推断总体 | 成本低、速度快、应用广 | 存在抽样误差 | 居民收入调查、市场调查 |
| 统计报表 | 按制度上报 | 自下而上、定期报送 | 连续、稳定、可比 | 灵活性较弱 | 企业月报、部门统计报表 |
| 重点调查 | 部分重点单位 | 抓住对总体影响大的单位 | 省时、能把握主要情况 | 不能全面推断总体 | 重点企业、重点地区调查 |
| 典型调查 | 典型单位 | 选择有代表性的单位深入调查 | 深入具体、便于分析原因 | 主观性较强 | 典型村、典型企业案例 |

### 2. 一句话区分

| 形式 | 简单记忆 |
| --- | --- |
| 普查 | 全部都查 |
| 抽样调查 | 抽一部分来推断全部 |
| 统计报表 | 按制度定期上报 |
| 重点调查 | 抓主要单位 |
| 典型调查 | 找代表单位深入分析 |

### 3. 易混淆点

- 重点调查不等于抽样调查。重点调查选择的是“重要单位”，不一定随机。
- 典型调查不等于普查。典型调查只调查少数有代表性的单位。
- 统计报表强调制度化和连续性，不是临时设计的调查。
- 抽样调查的关键是样本代表性，尤其是概率抽样更适合进行总体推断。

### 例题

例题 1：全国每十年进行一次人口普查，这属于哪种统计调查组织形式？

答案：普查。因为调查对象是全国人口，调查范围覆盖全部单位，目的是全面掌握人口资料。

例题 2：为了快速了解某品牌饮料在大学生中的受欢迎程度，调查人员抽取 800 名大学生进行问卷调查。这属于哪种组织形式？

答案：抽样调查。因为只调查总体中的一部分学生，并希望用样本情况推断大学生总体态度。

例题 3：某部门要求各企业每月按统一表格上报产量、销售额和库存数据。这属于哪种组织形式？

答案：统计报表。因为它是按制度、定期、自下而上报送统计资料。

## 五、抽样调查和普查

### 1. 对比表

| 比较项目 | 普查 | 抽样调查 |
| --- | --- | --- |
| 调查范围 | 总体全部单位 | 总体中的一部分单位 |
| 目的 | 获得全面资料 | 用样本推断总体 |
| 成本 | 高 | 较低 |
| 时间 | 长 | 较短 |
| 工作量 | 大 | 较小 |
| 误差特点 | 主要可能有登记性误差 | 有登记性误差，也有抽样误差 |
| 适用对象 | 总体规模可控，资料要求全面 | 总体较大，要求及时、经济 |
| 例子 | 全国人口普查 | 居民消费抽样调查 |

### 2. 适用情况

适合普查的情况：

- 需要全面掌握总体资料。
- 调查周期较长也可以接受。
- 调查对象较重要，必须系统登记。

适合抽样调查的情况：

- 总体数量很大。
- 时间和经费有限。
- 不需要逐一掌握每个单位的信息。
- 可以通过科学抽样推断总体。

### 3. 易混淆点

- 普查不是一定没有误差。普查虽然没有抽样误差，但仍可能有登记性误差。
- 抽样调查不是“随便调查一些人”。科学抽样需要设计抽样框、抽样方法和样本量。
- 抽样调查的结果不是样本本身，而是通过样本推断总体。
- 样本越大通常误差越小，但样本代表性比单纯样本量更重要。

### 例题

例题 1：某市要全面掌握所有常住人口的年龄、性别、受教育程度等资料，应采用普查还是抽样调查？

答案：应采用普查。因为需要全面掌握所有常住人口的基本资料，调查对象应覆盖全部单位。

例题 2：某企业想了解消费者对新包装的喜好，但时间和经费有限，应采用普查还是抽样调查？

答案：应采用抽样调查。因为消费者总体数量较大，逐一调查成本高，通过科学抽样可以较快获得总体判断。

例题 3：判断正误：普查调查全部单位，所以一定没有误差。

答案：错误。普查没有抽样误差，但可能存在填报、记录、录入等登记性误差。

## 六、统计分组

### 1. 概念

统计分组是根据统计研究的目的和要求，将总体单位按照某一标志划分为若干组的方法。

简单理解：

```text
杂乱数据 → 按某个标志分组 → 看结构、差异和规律
```

### 2. 统计分组的作用

| 作用 | 说明 | 例子 |
| --- | --- | --- |
| 划分总体类型 | 把总体分成不同类别 | 按专业分组学生 |
| 反映结构比例 | 看各部分占比 | 各收入组人数占比 |
| 揭示依存关系 | 分析两个现象之间的联系 | 收入水平与消费水平的关系 |

### 3. 分组原则

| 原则 | 含义 | 易错提醒 |
| --- | --- | --- |
| 科学性 | 分组要符合研究目的 | 不要为了分组而分组 |
| 完备性 | 每个单位都能归入某一组 | 不能漏掉某些取值 |
| 互斥性 | 每个单位只能归入一个组 | 组与组不能交叉重叠 |

### 4. 分组类型

| 分类角度 | 类型 | 例子 |
| --- | --- | --- |
| 按标志性质 | 品质标志分组 | 按性别、地区、专业分组 |
| 按标志性质 | 数量标志分组 | 按年龄、收入、成绩分组 |
| 按标志多少 | 简单分组 | 只按性别分组 |
| 按标志多少 | 复合分组 | 先按性别，再按成绩分组 |

### 5. 数量标志分组中的关键概念

| 概念 | 含义 |
| --- | --- |
| 组限 | 每组两端的数值 |
| 上限 | 每组的最大边界值 |
| 下限 | 每组的最小边界值 |
| 组距 | 每组区间长度 |
| 组中值 | 上限与下限的中点 |
| 开口组 | 只有上限或只有下限的组 |

常用公式：

```text
组距 = 上限 - 下限
组中值 = (上限 + 下限) / 2
```

开口组组中值的估算：

```text
缺下限的第一组：组中值 = 上限 - 相邻组组距 / 2
缺上限的最后一组：组中值 = 下限 + 相邻组组距 / 2
```

### 6. 易混淆点

- 组距相同叫等距分组；组距不同叫不等距分组。
- 等距分组可以直接比较频数；不等距分组应比较频数密度。
- 如果某个变量值正好等于组限，通常按“上限不在内、下限在内”的原则归入下一组，具体以题目规定为准。
- 组数不是越多越好，也不是越少越好。组数过多会过细，组数过少会掩盖差异。

### 例题

例题 1：将学生按“专业”分为金融学、会计学、统计学等组，属于什么分组？

答案：属于品质标志分组。因为“专业”反映的是类别属性，不是数量大小。

例题 2：将员工按月收入分为 3000 元以下、3000-5000 元、5000-8000 元、8000 元以上，属于什么分组？其中“3000 元以下”和“8000 元以上”是什么组？

答案：属于数量标志分组。“3000 元以下”和“8000 元以上”属于开口组，前者缺下限，后者缺上限。

例题 3：某分组为 60-70、70-80、80-90。如果某学生成绩为 80 分，通常应归入哪一组？

答案：通常归入 80-90 这一组。常见处理原则是“下限在内，上限不在内”，即 70-80 包含 70 但不包含 80；具体仍以题目说明为准。

## 七、直方图、向上累计和向下累计

### 1. 先区分：直方图与累计图

严格来说：

- 直方图主要用于显示分组数值型数据的频数或频率分布。
- 向上累计、向下累计通常用于累计频数或累计频率分布，可画成累计分布表或累计曲线。

在学习中常把它们放在同一部分，是因为它们都来自同一张分组频数表。

### 2. 直方图

直方图用于展示分组数据的频数分布。

| 项目 | 说明 |
| --- | --- |
| 横轴 | 各组区间 |
| 纵轴 | 频数、频率或频数密度 |
| 矩形宽度 | 表示组距 |
| 矩形高度 | 等距分组时可表示频数或频率；不等距分组时应表示频数密度 |

易错点：

- 直方图不是柱形图。柱形图用于分类数据，直方图用于数值型分组数据。
- 等距分组时，矩形高度可以直接用频数。
- 不等距分组时，不能直接用频数作高度，应使用频数密度。

### 3. 向上累计

向上累计也叫“以下累计”，通常从小到大逐组累计。

含义：

```text
某组的向上累计频数 = 该组及其以下各组频数之和
```

解释：

- 表示“不超过某一上限”的单位数。
- 常用于回答“低于或不超过某个水平的有多少”。

例：

| 成绩分组 | 频数 | 向上累计频数 |
| --- | ---: | ---: |
| 60 以下 | 5 | 5 |
| 60-70 | 12 | 17 |
| 70-80 | 20 | 37 |
| 80-90 | 10 | 47 |
| 90 以上 | 3 | 50 |

解释：70-80 这一组的向上累计频数为 37，表示成绩不超过 80 分的大约有 37 人。

### 4. 向下累计

向下累计也叫“以上累计”，通常从大到小逐组累计。

含义：

```text
某组的向下累计频数 = 该组及其以上各组频数之和
```

解释：

- 表示“不低于某一下限”的单位数。
- 常用于回答“高于或达到某个水平的有多少”。

例：

| 成绩分组 | 频数 | 向下累计频数 |
| --- | ---: | ---: |
| 60 以下 | 5 | 50 |
| 60-70 | 12 | 45 |
| 70-80 | 20 | 33 |
| 80-90 | 10 | 13 |
| 90 以上 | 3 | 3 |

解释：80-90 这一组的向下累计频数为 13，表示成绩不低于 80 分的大约有 13 人。

### 5. 向上累计与向下累计对比

| 比较 | 向上累计 | 向下累计 |
| --- | --- | --- |
| 累计方向 | 从小到大 | 从大到小 |
| 又称 | 以下累计 | 以上累计 |
| 关注问题 | 不超过某一水平有多少 | 不低于某一水平有多少 |
| 数值变化 | 越往后越大 | 越往后越小 |
| 常用端点 | 各组上限 | 各组下限 |

### 6. 常见题目问法

| 题目问法 | 应使用 |
| --- | --- |
| 不超过 80 分的人数 | 向上累计 |
| 80 分及以上的人数 | 向下累计 |
| 低于某收入水平的人数 | 向上累计 |
| 达到某收入水平以上的人数 | 向下累计 |
| 画累计频率曲线 | 根据题意选择向上累计或向下累计 |

### 7. 总结口诀

```text
直方图看各组分布；
向上累计看“不超过”；
向下累计看“不低于”。
```

### 例题

例题 1：某班成绩分布如下表，计算向上累计频数。

| 成绩分组 | 频数 |
| --- | ---: |
| 60 以下 | 4 |
| 60-70 | 8 |
| 70-80 | 16 |
| 80-90 | 10 |
| 90 以上 | 2 |

答案：

| 成绩分组 | 频数 | 向上累计频数 |
| --- | ---: | ---: |
| 60 以下 | 4 | 4 |
| 60-70 | 8 | 12 |
| 70-80 | 16 | 28 |
| 80-90 | 10 | 38 |
| 90 以上 | 2 | 40 |

解释：向上累计从低分组开始累加，表示“不超过某一上限”的人数。

例题 2：仍用上题数据，计算向下累计频数。

答案：

| 成绩分组 | 频数 | 向下累计频数 |
| --- | ---: | ---: |
| 60 以下 | 4 | 40 |
| 60-70 | 8 | 36 |
| 70-80 | 16 | 28 |
| 80-90 | 10 | 12 |
| 90 以上 | 2 | 2 |

解释：向下累计从高分组开始累加，表示“不低于某一下限”的人数。

例题 3：某组距分组如下：1000-2000 元有 20 人，2000-4000 元有 30 人，4000-7000 元有 45 人。能否直接用频数作为直方图高度？为什么？

答案：不能。因为各组组距分别为 1000、2000、3000，属于不等距分组。直方图高度应使用频数密度，即频数除以组距。
